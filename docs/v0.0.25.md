
📦 0.0.25 详细更新

🎯 核心目标

把 JS 语法规则从硬编码在 Kotlin 代码里，搬到外部 JSON 文件，实现"加语言 = 加文件"。

---

📁 新增文件

1. app/src/main/assets/syntax/Web/javascript.json

出厂自带的 JS 语法规则，包含：

· name：JavaScript
· extensions：js, jsx, mjs, cjs, ts, tsx
· keywords：60+ 个 JS 关键字（声明、控制流、操作、模块、异步等）
· lineCommentPrefix：//
· blockCommentStart / blockCommentEnd：/* */
· stringDelimiters：" '  ` 

2. app/src/main/java/com/kitty/ide/data/syntax/SyntaxLoader.kt

语法文件加载器，负责：

· 首次启动：把 assets 里的语法复制到用户目录
· 每次启动：hash 比对，决定是否覆盖
· 遍历用户目录加载所有 json → 组装成 Map<String, LanguageRule>
· 通过 LanguageRegistry.setRules() 推给 UI

---

🔧 修改文件

3. LanguageRule.kt

加了 fromJson(json: JSONObject) 静态方法，把 JSON 解析成 LanguageRule 数据类。字段缺失时用默认值兜底。

4. LanguageRegistry.kt

从"硬编码 val JAVASCRIPT = LanguageRule(...) + all 列表"，改成：

· _rules: MutableStateFlow<Map<String, LanguageRule>>
· setRules()：SyntaxLoader 加载完成后调用
· forFileName()：从当前规则表里按扩展名查

5. MainActivity.kt

加了 SyntaxLoader.init(this) 和后台协程：

```kotlin
lifecycleScope.launch {
    SyntaxLoader.loadAll()
}
```

不阻塞启动页，用户看到的还是启动页，扫描在后台跑。

6. EditorScreen.kt

只改了一处逻辑：

```kotlin
val rules by LanguageRegistry.rules.collectAsState()
val activeLanguage = remember(activeFileName, rules) {
    activeFileName?.let { LanguageRegistry.forFileName(it) }
}
```

订阅 rules：加载完成前 rules 是空的 → 无高亮；加载完成后 rules 变化 → UI 自动重组 → 高亮出现。

📂 目录结构（新增）

用户目录：/sdcard/Documents/Kitty/.code/syntax/

```
.code/syntax/
└── Web/                    ← 插件（或语言组）
    ├── javascript.json     ← 用户可编辑
    └── .sync.json          ← 同步状态（记录每个 json 的 hash）
```

设计成"插件"概念：以后加 CSS、HTML 就是往 Web/ 里丢 json；加 Python 就可以开 Python/ 目录。

---

🔄 同步策略（D 方案）

每次启动时的判断：

用户改过？ 内置更新？ 处理
没改 没更新 跳过
没改 更新了 覆盖用户文件，更新 .sync.json
改了 没更新 跳过，保留用户的
改了 更新了 另存 javascript.new.json，不覆盖用户文件

判定方式：

· 用户文件 hash == .sync.json 里的 hash → 用户没改过
· assets hash != .sync.json 里的 hash → 内置更新了

优点：

· 用户改过的语法不会被强覆盖
· 内置更新时用户能看到新版（xxx.new.json）
· 用户手动加的语法文件（assets 里没有的）也会被保留

🎨 行为对比

0.0.24（硬编码）

· 加语言要改 LanguageRegistry.kt 代码
· 改关键字要重新编译 APK
· 用户无法自定义

0.0.25（外部化）

· 加语言 = 往 Web/ 里丢一个 json
· 改关键字 = 编辑 json，重启 App
· 用户可自定义，改坏了删掉重来
