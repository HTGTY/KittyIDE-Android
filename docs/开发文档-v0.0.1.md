Kitty IDE 项目文档

版本：0.0.1
状态：需求确认完毕，待开发

---

一、项目概述

Kitty IDE 是一个 Android 端轻量级代码编辑器，风格参考 VS Code，主打扁平化、精简。0.0.1 版本聚焦「编辑」这一核心能力，不做运行、不做 AI，但为后续扩展预留接口。

---

二、需求确认清单

项目 决定
语言 Kotlin + Java（UI 用 Kotlin/Compose，工具类可用 Java）
支持库 AndroidX 等
支持文件类型 HTML / JS / CSS
0.0.1 范围 只做编辑，不做运行
编辑器内核 WebView + CodeMirror 6
文件管理 多文件 + 简单文件树（预留标签页）
文件树交互 左上角三条杠，点击后从左向右平滑滑出，编辑区被向右挤压
存储 启动时创建/打开项目，用户选择路径
项目操作 支持「打开已有项目」+「新建项目」
UI 框架 Jetpack Compose
主题 深色 + 浅色，可切换
AI 0.0.1 不做
运行/预览 0.0.1 不做，预留接口

---

三、技术栈

· 语言：Kotlin（主）+ Java（工具类）
· UI：Jetpack Compose + Material 3
· 编辑器：WebView + CodeMirror 6（打包在 assets）
· 通信：WebView JavaScript Bridge
· 存储：SAF（Storage Access Framework）+ 持久化 URI 权限
· 异步：Kotlin Coroutines + Flow
· 依赖注入：0.0.1 可先不用，或轻量用 Hilt（可选）

---

四、架构设计

采用简单的 MVVM 分层：

```
UI (Compose)
   ↓
ViewModel (状态 + 业务)
   ↓
Repository (文件读写 / 项目管理)
   ↓
Data Source (SAF / WebView Bridge)
```

模块划分

模块 职责
ui/ Compose 页面、主题、组件
viewmodel/ 各页面状态与逻辑
data/ 项目、文件、存储读写
editor/ WebView 封装、CodeMirror Bridge
theme/ 深浅色配色
util/ 工具类（Java/Kotlin）

五、页面设计

1. 启动页 / 项目选择页

· 顶部：Kitty IDE Logo + 名称
· 两个按钮：
  · 新建项目 → 选父目录 → 输入项目名 → 创建
  · 打开项目 → 选已有目录 → 进入
· 最近项目列表（本地记录，可选）

2. 编辑器主页面

```
┌─────────────────────────────────┐
│ ☰  文件名.html          🌓  ⋮   │  ← 顶栏
├──────────┬──────────────────────┤
│          │                      │
│  文件树   │    CodeMirror 编辑区  │
│ (可滑出)  │                      │
│          │                      │
├──────────┴──────────────────────┤
│  {} () ; Tab  ←  →  ↑  ↓        │  ← 符号栏
└─────────────────────────────────┘
```

· 左上角 ☰：点击后文件树从左向右平滑滑出，编辑区被向右挤压
· 右上角 🌓：切换深浅主题
· 右上角 ⋮：菜单（保存、新建文件、删除文件等）
· 底部符号栏：常用符号 + 光标移动

3. 文件树（侧栏）

· 显示当前项目下的 .html / .js / .css 文件
· 点击切换文件
· 长按：重命名 / 删除
· 顶部：新建文件按钮

七、关键实现点

1. CodeMirror 6 集成

· 将 CodeMirror 6 打包为单文件 JS，放入 assets/editor/
· WebView 加载 file:///android_asset/editor/index.html
· 通过 @JavascriptInterface 暴露：
  · getContent(): String
  · setContent(text: String)
  · setTheme(mode: String)
  · setLanguage(lang: String)
· JS 侧监听内容变化，回调 Android 更新 isDirty

2. 文件树滑出动画

· 用 Compose 的 AnimatedVisibility + Row 布局
· 文件树宽度动画从 0dp → 240dp
· 编辑区用 weight(1f) 自动被挤压
· 用 animateFloatAsState 控制宽度，保证平滑

3. SAF 选目录

· ActivityResultContracts.OpenDocumentTree
· 拿到 URI 后 takePersistableUriPermission 持久化
· 用 DocumentFile 遍历目录，按扩展名过滤

4. 主题切换

· Compose 侧：MaterialTheme 两套 colorScheme
· CodeMirror 侧：两套主题 CSS，通过 Bridge 切换
· 状态存在 DataStore，下次启动恢复
