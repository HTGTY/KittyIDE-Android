0.0.29 更新总结

主题：HTML 内嵌 JS/CSS 高亮

做了什么：

· HTML 里的 <script> 内容现在用 JS 规则高亮
· HTML 里的 <style> 内容现在用 CSS 规则高亮
· 标签名本身还是按 HTML 标签色显示

核心机制：

· 新增 childrenSyntax 字段，让区域能"切换"到另一门语言的规则
· 新增 LanguageResolver，解决跨语言的引用问题
· RegionRule 支持子语言扫描 + 不断尝试 end 退出

效果：Web 三件套（HTML + JS + CSS）高亮完整闭环，HTML 里嵌的 JS/CSS 各按各的规则上色喵～😼
