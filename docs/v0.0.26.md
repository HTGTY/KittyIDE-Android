0.0.26 · DSL 加正则

目标：给语法规则 DSL 加"正则"能力，为后续做 CSS/HTML 铺路。

核心变化：DSL 格式统一

之前是"独立字段"：

```json
{
  "keywords": ["const", "let"],
  "lineCommentPrefix": "//",
  "stringDelimiters": ["\"", "'"]
}
```

改成"统一的 rules 数组"（B 方案）：

```json
{
  "rules": [
    {"type": "lineComment", "prefix": "//", "token": "comment"},
    {"type": "blockComment", "start": "/*", "end": "*/", "token": "comment"},
    {"type": "string", "delimiters": ["\"", "'"], "token": "string"},
    {"type": "number", "token": "number"},
    {"type": "regex", "pattern": "[+\\-*/%=<>!&|^~?]+", "tokens": {"0": "operator"}},
    {"type": "keyword", "words": ["const", "let"], "token": "keyword"}
  ]
}
```

新增 SyntaxRule.kt，六种规则类型：

· LineCommentRule / BlockCommentRule / StringRule / NumberRule / KeywordRule / RegexRule

Lexer 改造：从"硬编码判断"改成"按规则顺序尝试匹配"，规则顺序 = 优先级。

javascript.json 迁移到新格式。
