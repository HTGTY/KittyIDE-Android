0.0.27 · HTML 高亮

目标：给 HTML 做基础高亮，同时把规则体系升级成支持"嵌套区域"。

TokenType 扩展：

· 新增 TAG_NAME / ATTR_NAME / META

规则体系大改：

· tryMatch 参数从 start 改成 pos（避免和 RegionRule.start 字段冲突）
· 新增 PatternMatch：正则 + 捕获组样式映射（比如 <div → < 是标点，div 是标签名）
· 新增 RegionRule：start/end 配对 + 内部规则扫描（HTML 的注释、DOCTYPE、标签都靠它）
· RuleMatch 返回"多个 token + 结束位置"
