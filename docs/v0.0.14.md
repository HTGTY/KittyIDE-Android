0.0.14 完成的功能

1. 文件操作增强
   · 长按文件 → 菜单：重命名 / 复制路径 / 删除
   · 长按目录 → 菜单：新建文件/文件夹/HTML/CSS/JS + 重命名 / 复制路径 / 删除
   · 长按空白 → 保留原有的"项目根目录新建"菜单
   · 重命名后，打开列表里对应的标签路径自动更新，内容不丢
   · 删除目录时，打开列表里该目录下的所有文件自动关闭
2. 命名校验（应用到项目名、文件名、文件夹名、重命名）
   · 禁止字符：/ \ : * ? " < > |
   · 不能以 . 开头
   · 首尾不能有空格
   · 长度 ≤ 50
   · 校验失败时输入框下方显示红色错误提示，光标停在弹窗里方便改
